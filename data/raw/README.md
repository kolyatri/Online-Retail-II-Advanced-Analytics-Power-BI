# Raw Data

This project uses the **Online Retail II** dataset from the  
UCI Machine Learning Repository.

The raw data file (`online_retail_ii.csv`) is **not included** in this repository
to keep the project lightweight and to follow data sharing best practices.

Dataset source:
https://archive.ics.uci.edu/ml/datasets/Online+Retail+II

The raw dataset contains invoice-level transactional data and serves as the
starting point for all further analysis.
