# Processed Data

This directory is intended for **intermediate and analysis-ready datasets**
generated during data cleaning and feature engineering.

Processed files are **not included** in the repository to avoid large file sizes
and unnecessary duplication of derived data.

All transformations and aggregation logic used to create these datasets
are fully documented in the project notebooks.

The final analytical results are presented through:
- SQL analysis
- Power BI dashboards
- Insights summary notebooks
